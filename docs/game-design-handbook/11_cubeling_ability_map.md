# Cubeling Ability Map

Track each Cubeling, status, likely uses, and source confidence so planning and implementation stay aligned.

## Status key

- `LOCKED / CURRENT DIRECTION`
- `STRONG CANDIDATE`
- `EXPLORATORY / BACKLOG`
- `OPTIONAL / DEFERRED`
- `AI-SUGGESTED / NEEDS HUMAN REVIEW`
