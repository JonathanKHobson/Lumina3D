# Bonus Biomes, Surfaces, And Magic Level Language

## Purpose

This doc links terrain/surface readability to Cubeling candidates and future special biomes.

## Biome specialist mapping

### Axolotl

- Terrain: water
- Meaning: water traversal
- Status: `STRONG CANDIDATE / FUTURE WATER CUBELING`
- Source: `Direct user idea`

### Tortoise

- Terrain: hot desert / heated sand
- Meaning: heat-resistant traversal
- Status: `STRONG CANDIDATE / FUTURE BIOME SPECIALIST`
- Source: `Direct user idea`

### Penguin

- Terrain: snow / cold ice
- Meaning: cold-tile traversal
- Status: `STRONG CANDIDATE / FUTURE BIOME SPECIALIST`
- Source: `Direct user idea`

### Mole

- Terrain: mud, dirt, burrow, cracked soil
- Meaning: hidden/buried underworld movement
- Status: `STRONG CANDIDATE / FUTURE LEVEL IDEA`
- Source: `Direct user idea`

### Unicorn (bonus)

- Terrain: pink magical ground and pink trees
- Meaning: magical/fantasy bonus access
- Status: `OPTIONAL / DEFERRED`
- Source: `Direct user idea`, `Needs asset review`

## Terrain as language

Player should be able to infer specialist from terrain:

- Water cue -> think Axolotl.
- Hot sand/desert cue -> think Tortoise.
- Snow/ice cue -> think Penguin.
- Dirt/burrow cue -> think Mole.
- Pink magical cue -> think Unicorn.

## Source labels and confidence

- Existing locked candidates (Frog/Elephant movement language) stay unchanged.
- These biome pairings are currently:
  - `STRONG CANDIDATE` except Unicorn (deferred),
  - none are implementation requirements yet.
